# NEON RUSH — 3D Racing Game

Three.js로 만든 브라우저 기반 3D 레이싱 게임입니다. 플레이어는 3명의 AI 라이벌(KIRA, VOLT, NOVA)과 함께 미드나이트 서킷을 3랩 동안 달립니다.

## 게임 시작하기

이 프로젝트는 별도 설치나 빌드 과정이 필요 없습니다. 다만 Three.js와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

1. 터미널에서 프로젝트 폴더로 이동합니다.

   ```bash
   cd racing-game
   ```

2. 간단한 로컬 서버를 실행합니다.

   ```bash
   python3 -m http.server 8000
   ```

3. 브라우저에서 [http://localhost:8000](http://localhost:8000)를 엽니다.

4. 화면 중앙의 **ENGINE START** 버튼을 누르면 카운트다운 후 레이스가 시작됩니다.

서버를 종료하려면 터미널에서 `Ctrl + C`를 누르세요.

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` 또는 `↑` | 가속 |
| `S` 또는 `↓` | 브레이크 |
| `A` 또는 `←` | 왼쪽 조향 |
| `D` 또는 `→` | 오른쪽 조향 |
| `Space` | 부스트 사용 |

부스트는 사용하지 않을 때 천천히 충전됩니다. 트랙 가장자리 바깥으로 나가면 감속되므로, 코너에서 조향을 과하게 하지 않도록 주의하세요.

## 승리 조건

세 바퀴를 완주하면 경기가 끝납니다. 결승선 통과 순위와 최종 시간이 표시되며, **RACE AGAIN**으로 즉시 다시 달릴 수 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면과 HUD 구조 |
| `style.css` | 네온 스타일 UI 및 반응형 레이아웃 |
| `game.js` | 3D 트랙, 차량, AI 경쟁자, 조작 및 레이스 규칙 |
